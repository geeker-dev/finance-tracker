# Архитектура: Финансовый трекер (PWA)

Личное веб-приложение для учёта трат и накоплений по мотивам ZenMoney. Один пользователь, русский язык, тёмная тема, установка на экран «Домой» (iPhone).

## Стек

- Frontend: Vite + React + TypeScript, Tailwind, React Router, TanStack Query, `vite-plugin-pwa`.
- Графики: собственные SVG-бары (Recharts не нужен).
- Backend: Supabase (Postgres, RLS, Auth, Edge Functions) — бесплатный тариф.
- Хостинг: Cloudflare Pages (или Vercel), нужен SPA-fallback на `index.html`.

## Ключевые решения

| Тема | Решение |
|---|---|
| Деньги | `bigint` в минимальных единицах, валюта живёт на счёте (UAH / USD / USDT, 2 знака) |
| Вход | Supabase email + пароль, один раз на устройство, долгая сессия. Magic link/OTP отклонены: без своего SMTP Supabase не даёт править шаблон письма (кода нет), а ссылка на iOS открывается в Safari, а не в установленной PWA. Confirm email выключен; после создания аккаунта отключить signups |
| Безопасность | RLS на всех таблицах, `user_id = auth.uid()`; в клиенте только anon key |
| Баланс | Не хранится, считается view `account_balances` |
| Переводы | Одна строка: `amount_minor` с `account_id`, `to_amount_minor` на `to_account_id`; курс не хранится |
| Начальный остаток | `kind = 'adjustment'` (сумма со знаком), он же используется для сверки |
| Цели | Привязаны к счёту накоплений: прогресс = баланс счёта |
| Общий баланс | Показываем суммы по валютам (₴ / $ / ₮), без конвертации |
| Бюджеты | Месячные, по категории, учитывают только расходы в валюте бюджета (старт — UAH) |
| Часовой пояс | `timestamptz`; группировка Daily/Weekly/Monthly в `Europe/Kyiv`, неделя с понедельника |
| Удаление | Счета и категории с транзакциями архивируются (`ON DELETE RESTRICT` + `archived`) |
| Офлайн (MVP) | Только кэш чтения (`persistQueryClient` + precache оболочки). `id` транзакций — UUID с клиента, чтобы позже добавить очередь записей |

## iOS-нюансы

`viewport-fit=cover` и `env(safe-area-inset-*)` для нижней навигации; шрифт в инпутах не меньше 16px; `inputmode="decimal"` для сумм; `apple-touch-icon`; `backdrop-filter` только на карточках и навбаре; обновление SW через `registerType: 'prompt'` с тостом «Доступна новая версия».

## Push-уведомления (v1.1)

Web Push (VAPID) работает на iOS 16.4+ только из установленной PWA и только по тапу пользователя. На странице «Напоминания» вне standalone-режима показываем подсказку, как добавить приложение на экран «Домой». Отправка — Edge Function `push` по `pg_cron` каждый час; кому пора слать, решает SQL-функция `users_due_for_reminder()` (час по Киеву, есть подписка, нет операций за день), поэтому переход на летнее время ничего не ломает. Ключи VAPID создаются функцией при первом вызове и лежат в `push_config` (доступна только service_role); cron вызывает функцию с секретом из той же таблицы. Подписки с ответом 404/410 удаляются. Предупреждение о превышении бюджета — тостом в приложении, а не пушем.

## Бэкапы и надёжность бесплатного Supabase

- Проект засыпает после 7 дней без активности → GitHub Actions cron с keep-alive пингом.
- Бэкапов на бесплатном тарифе нет → еженедельный `pg_dump` через GitHub Actions + кнопка «Экспорт JSON» в приложении.

## Порядок реализации

1. Каркас приложения, дизайн-токены тёмной темы, нижняя навигация с «+».
2. Supabase: миграции (`supabase/migrations`), RLS, типы.
3. Авторизация по OTP.
4. Счета, форма транзакции (расход / доход / перевод), главный экран, список операций.
5. PWA: manifest, иконки, precache, обновления.
6. Статистика (SVG-бары) и бюджеты.
7. Цели, экспорт, GitHub Actions.
8. v1.1: теги, офлайн-очередь (push уже сделан).
